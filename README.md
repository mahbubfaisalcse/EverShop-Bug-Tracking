# Evershop Bug Tracking Project

## Project Overview
This repository contains bug reports identified during manual testing of the Evershop E-Commerce Website.
The project demonstrates practical Software Quality Assurance (SQA) skills including:
-Bug Identification
-Bug Documentation
-Severity & Priority Analysis
-Reproducible Test Evidence

## Tools & Technologies Used
-Jira
-Microsoft Excel / CSV
-Manual Testing
-Bug Reporting
-Video Evidence

## Project Contents
-File Name	Description
-Evershop-bug-tracking.xltx	Complete bug tracking sheet with reported issues

## Testing Scope
The following modules were tested:
-User Authentication
-Product Search
-Cart Functionality
-Checkout Process
-UI/UX Validation
-Form Validation
-Navigation
-Responsive Behavior

## Bug Report Format
Each bug report contains:
-Bug ID
-Summary
-Description
-Steps to Reproduce
-Expected Result
-Actual Result
-Severity
-Priority
-Status
-Video Evidence

## Sample Bug Categories
-Functional Bugs
-UI Bugs
-Validation Errors
-Performance Issues
-Navigation Problems
-Compatibility Issues

## Purpose of This Project
This project was created to practice and demonstrate:
-Real-world bug tracking workflow
-QA documentation standards
-Defect lifecycle understanding
-Attention to detail in software testing

## How to Use
-Download the bug tracking file
-Open using Microsoft Excel
-Review reported bugs and testing observations
